## 目标

## 输出前 QC

发给 image2 前必须静默检查：

1. 是否还出现真人 / 写实真人 / photorealistic / real human / metahuman / pores 等词。
2. 是否出现真实岁数数字。
3. 是否把职业介绍、阶层介绍、人设介绍直接塞进 prompt。
4. 是否仍有“正脸特写肖像 / 直视镜头 / 人像 / 肖像 / 真实皮肤 / 卧蚕 / 双眼皮 / 唇峰 / 肤色”等真人触发词。
5. 是否保留了角色核心设定：脸型、发型、服装、标志物、状态变化、身份锚点。
6. 是否保留左 50% 面部角色设定展示 + 右 50% 1x3 服装三视图。
7. 是否包含强“负面提示”。

任一项不通过，必须先替换为 3D 动画角色资产术语，再输出最终提示词。
