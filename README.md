## 🇬🇧 English

Four skills for short-drama production and video prompting: one that gets the prompt right and three that run the full pipeline. award-winning-performance-prompt-v1-1 starts with input recognition, task-type detection, image/video asset role analysis and shot analysis, then applies the Seedance 2.0 prompt formula to spell out subject, scene, environment, character and duration. short-drama-full-pipeline0730, 0801 and 0802 are three dated full-pipeline builds covering the whole chain from a short-drama idea, genre, story outline and character relations through episode and scene breakdowns and a literary script, then asset decomposition, character/scene/prop reference-image planning, stage positioning, storyboards and video generation. All three carry a local chain lock and a mandatory launch dialog — realistic live-action mode versus 3D animated CG mode — followed by a second dialog for style and tonal configuration. They are meant to be used together: the prompt formula drives whichever pipeline version you pick, from one idea to a finished cut.

> ⚠️ **A cooperating suite of 4 skills** — they reference each other; use them as a group.

### ✨ What it does

- Input recognition: detect task type and the role of each asset, and analyze images or video before choosing how to write the prompt
- Seedance 2.0 prompt formula: decompose subject, scene, environment and character item by item before drafting
- Three full pipelines (0730 / 0801 / 0802): idea to script, assets, storyboard and video generation
- Mandatory launch dialogs: realistic live-action versus 3D animated CG, then a second dialog for style and tonal setup
- Local chain lock plus a top-priority rule index across the whole chain to prevent partial execution and rule rollback
- Asset decomposition: character, scene and prop reference-image planning, stage positioning and storyboard handoff
